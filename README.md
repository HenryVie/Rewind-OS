# Rewind-OS
A retro Linux distro which designed for feeling comfortable. Brings the vibe inspired by Windows 98 but still have modern convenient.

Rewind OS is a Fedora-based Linux distribution project focused on combining a retro desktop experience with modern applications and built-in AI tools.

## Vision

- Classic Windows 98 inspired interface
- Modern Linux foundation
- Beginner-friendly experience
- Built-in maintenance tools
- AI-assisted features
- Lightweight and practical
