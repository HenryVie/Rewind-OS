# Rewind Settings Changelog

## 04/6/2026
### Version Prototype 1.0
- The first prototype of Rewind Settings
- Added Settings menu
- Added temporary sub-menu for Personalization feature
- Added feature: About. This feature opens the About document from Kineat's database
### Version Prototype 1.1
- Modified feature: About. Now, About in settings will show the information of distro version, developer, based-distro version, kernel version, hostname, and desktop environment version
- Added 4 wallpapers for future Change wallpaper feature
### Version Prototype 1.2
- Added feature: Change wallpaper. Now, user can choose to change desktop wallpaper from the listed existing wallpapers
### Version Prototype 1.2.1
- Modified wallpaper path. The existing wallpaper paths used $HOME instead of /home/user-name/ for absolute correct paths
### Version Prototype 1.2.2
- Added 4 new wallpapers for the user to change

## 05/6/2026
### Version Prototype 1.3
- Added feature: Change default browser. Now, user can choose an installed browser to be their default web browser. Current list has Brave, Chromium, and Firefox
- Improved minor experience: Now, the menu will be put in a while loop. Thr user can choose to stay in the current menu or use features until they are pleased
- Improved minor Change wallpaper experience: From now, the program will output a message telling that the user's chosen image is now became their wallpaper
