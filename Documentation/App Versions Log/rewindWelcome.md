# Rewind Welcome Changelog

## 04/6/2026
### Version Prototype 1.0
- The first prototype of Rewind Welcome
- Added welcome menu
- Added feature: Set up my computer. This feature helps the user to go through the installation process
- Added feature: View Documentation. This feature allows the user to access Kineat Base database to read information about the distro
### Version Prototype 1.1
- Added feature: Settings. This feature launches Rewind Settings from Rewind Welcome
- Added feature: Technician. This feature launches Rewind Technician from Rewind Welcome
- Connected all existing Rewind apps with Rewind Welcome. From now, Rewind Welcome acts like a hub, it can launch the other Rewind apps from it, and those apps can be exited and return to Welcome
